# Facility Backend

Backend application built with Node.js, Express.js, and Oracle Database.

## Setup

1. Run `npm install` to install dependencies.
2. Update the `.env` file with your database credentials.
3. Place your Oracle Wallet files (`cwallet.sso`, `ewallet.p12`, `tnsnames.ora`, `sqlnet.ora`) in the `wallet` directory.
4. Run `npm run dev` to start the development server.
